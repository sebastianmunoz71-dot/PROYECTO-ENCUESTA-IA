# 📊 Sistema de Encuestas - Impacto de la IA

Proyecto universitario que implementa un sistema de captura de encuestas sobre el uso de la Inteligencia Artificial mediante una arquitectura **Cliente-Servidor**.

## 🚀 Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
* **Backend:** C++ (Sockets nativos con WinSock2 para Windows).
* **Almacenamiento / BD:** Persistencia de datos en formato `.csv` (compatible con Excel / SQLite).
* **Entorno de Desarrollo:** Visual Studio Code & MinGW-w64 (g++).
